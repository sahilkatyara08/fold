# fold

A single sheet of paper and one button. Press **Fold** and the sheet folds itself, panel by panel, into one of four paper toys, each of which comes alive once it's folded.

- **Pinwheel**: spins
- **Teller**: click to snap it open and shut
- **Balloon**: puffs up as if blown into, click to bounce
- **Frog**: click and it hops

Click the flat sheet to crumple it into a ball and watch it spring back. Drag to tilt the view. Space or Enter folds.

Built with [three.js](https://threejs.org) (r147) and [GSAP](https://gsap.com). Each toy is a hand-authored low-poly model whose panels tile the flat sheet and fly into place. One static `index.html`, no build step: deploy as-is on Vercel or any static host. Respects `prefers-reduced-motion`.

Fonts: Inter and JetBrains Mono via Google Fonts (SIL Open Font License).
